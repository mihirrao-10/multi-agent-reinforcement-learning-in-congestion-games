Multi-Agent Reinforcement Learning in Congestion Games

When Every Agent Finds the Shortcut

Eighty independent learners discover the same zero-cost link. The network gets slower.

Every point of light is an independent agent. Each chooses one complete route from source S to destination T, receives the negative of its travel cost as reward, and updates only the route value it just used.

One link through the center has zero direct cost. It looks irresistible. The experiment asks whether individual learning can stabilize on a routing pattern that makes everyone worse off.

Follow the learning process ↓

I

A route is an action

An action is not a turn at one junction. It is a complete directed route. The Upper route uses S → U → T. The Lower route uses S → V → T. The Shortcut route uses S → U → V → T.

An edge load is the integer number of agents whose selected routes contain that edge. An agent's route cost is the sum of the physical latency functions on its edges. Reward is the negative of perceived route cost, so a less costly trip produces a higher reward.

II

Everyone changes your reward

Let xU, xL, and xZ be the exact route counts. Shortcut users touch both congestion-sensitive edges, so they increase both loads.

The central filament remains free and pale even when crowded. The cost comes from sending its users through both variable bottlenecks. Those outer edges thicken, heat toward red, and slow the animated route cycles.

III

Each agent learns alone

Agent i stores one tabular value for each available route. All eighty agents select actions before any reward is evaluated. Then each updates only the selected entry:

The canonical run uses α = 0.15 and an epsilon-greedy schedule that decays from 0.80 to 0.01. There is no neural network because there are only two or three complete route actions.

From one learner's perspective, the other seventy-nine agents are part of the environment, and they are adapting too. That makes the reward process nonstationary. The site reports empirical stabilization in this finite potential game; it does not transfer the classic single-agent convergence theorem unchanged.

IV

The game has a hidden landscape

Every feasible count triple is one vertex in a triangular lattice. Height shows Rosenthal's potential, not social cost. For one unilateral route change, the player's cost change equals the potential change exactly:

A strict asynchronous best response therefore moves downhill by exactly the same amount as the agent's cost improvement. The warm path shows that finite improvement sequence. It ends because no accepted move can revisit a previous potential value.

Independent Q-learning is different: simultaneous updates and exploration can move uphill or fluctuate. Its empirical path is not claimed to descend monotonically.

VIII

Three ways to adapt

These algorithms use different information and support different statements. Independent Q-learning sees only experienced selected-route reward. Asynchronous best response sees exact unilateral costs. Hedge receives a full counterfactual cost vector.

IX

Answer

Individually sensible learning can stabilize on an inefficient outcome when the game rewards the wrong local behavior. Removing an edge or changing perceived prices changes which action is useful to each learner. Learning quality and incentive quality are separate questions.

The agents did not learn badly.
They learned the incentives they were given.

For the technically curious

One small game, completely audited

The browser never trains an agent. Python defines the atomic game, runs every experiment, derives exact benchmarks, selects representative runs, and exports all 3,321 landscape states. TypeScript validates and presents that immutable bundle.

Atomic model

Eighty labeled, unsplittable agents share one origin and destination. Each episode assigns every agent to one complete route. Edge loads are integers. Physical social cost is .

Exact deviations

To evaluate a candidate route, the implementation removes the deviating agent from its current route, adds it to the candidate, then recomputes affected loads. Exploitability is the largest available cost reduction.

Count-state enumeration

Symmetry reduces the open game from 380 labeled profiles to weak compositions. The closed game has 81 states. Exact rational arithmetic validates every feasible unilateral move.

Potential and welfare

Rosenthal potential proves finite strict-improvement paths terminate, but its minimum need not minimize physical social cost. The project computes all pure equilibria, all social optima, Price of Anarchy, and Price of Stability independently.

Independent Q-learning

There are eighty separate Q rows and no parameter sharing, controller, critic, replay buffer, or neural network. Gamma is zero because each repeated interaction is a one-stage decision. The final policy is evaluated separately at epsilon zero.

Regret and Hedge

For each agent and fixed route, cumulative counterfactual cost is recomputed against the realized opponents at every round. Stable log weights use full information. Mean and maximum per-round regret summaries remain in the export.

Representative runs

Each Q-learning and Hedge scenario uses 64 deterministic seeds. The representative is the medoid under pairwise L1 distance between final route counts, with exploitability and seed only as tie breakers. It is not selected for visual attractiveness.

Deterministic data

SeedSequence separates exploration, tie-breaking, initialization, aggregation, playback, and final evaluation streams. Stable ordering and finite JSON serialization make regeneration byte identical. Visible metrics always use an exact exported snapshot.

Visual encodings

Tube area encodes edge load through a square-root radius map. Hue encodes physical latency, with a permanently pale zero-cost shortcut. Particle density encodes assignments; route-cycle duration is proportional to physical route cost. Display height is an affine normalization of raw potential.

Experiment methodology

The canonical Q-learning configuration uses 5,000 episodes, α = 0.15, epsilon 0.80 × 0.999 per episode with floor 0.01, zero initial Q values, random greedy tie-breaking, and PCG64 generators rooted at seed 20260804. Hedge uses stable normalized log weights and exact full-information costs.

Limitations

  • The model is one atomic symmetric routing game with eighty agents sharing one origin and destination.
  • Agents choose one complete route per episode from two or three routes.
  • There is no continuous-time traffic, queueing, or physical road-capacity model beyond the authored latency functions.
  • Route costs are mathematical latency functions. Particles visualize discrete assignments and relative costs; they are not microscopic traffic.
  • Independent learners make each other's environments nonstationary; no general convergence theorem is claimed.
  • Behavior can depend on hyperparameters and exploration. Q-learning results here are empirical.
  • Hedge receives full counterfactual information; best response receives exact model information.
  • The toll result is specific to this authored finite instance. Toll payments are treated as transfers.
  • This is an educational computational study, not policy advice or a real traffic forecast.
